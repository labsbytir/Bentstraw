# quiz-match

## Purpose

Match visitors to tools/skills via a 3-question quiz.

## ADDED Requirements

### Requirement: Quiz returns matches

Submitting the quiz SHALL return up to 4 matching entries ranked by the same search index the site uses.

#### Scenario: Quiz match

- **WHEN** a visitor answers all 3 questions and submits
- **THEN** 1–4 entry cards render, each with name, blurb, and id.
